# Recursos e Assets Estáticos (`assets/`)

Contém os arquivos estáticos e configurações consumidas em tempo de execução pelo Petunia3D:

## Subdiretórios e Arquivos
- `keybinds/`: Mapeamentos de atalhos de teclado (ex: `petunia.toml`).
- `locales/`: Arquivos de tradução e internacionalização (i18n).
- `themes/`: Definições de cores e tokens de estilo para a interface gráfica.
- `tools.toml`: Metadados e parâmetros padrão das ferramentas de modelagem.
