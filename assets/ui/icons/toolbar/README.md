# Toolbar Icons (`assets/ui/icons/toolbar/`)

Ícones de ferramentas do viewport 3D extraídos com fidelidade pixel-perfect do design de referência (`Blender.svg`).

## Especificações Técnicas
- Formato: PNG 32-bit RGBA (Canal alfa transparente)
- Resolução nativa: 256x256 pixels
- Tingimento dinâmico: Renderizados em escala com tint dinâmico via `egui::Color32` (repouso `#BCBCBC`, hover `#FFFFFF`, ativo `#3169E3` com ícone branco).

## Lista de Ativos
- `select_box.png`: Seleção em caixa
- `cursor_3d.png`: Posicionador 3D Cursor
- `move.png`: Ferramenta de translação
- `rotate.png`: Ferramenta de rotação
- `scale.png`: Ferramenta de escala
- `transform.png`: Gizmo de transformação combinada
- `annotate.png`: Ferramenta de anotação/desenho livre
- `measure.png`: Ferramenta de medição de distância e ângulo
- `add_primitive.png`: Ferramenta de adição rápida de primitivas geométricas
