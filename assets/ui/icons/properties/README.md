# Properties Tabs Icons (`assets/ui/icons/properties/`)

Assets rasterizados extraídos do menu vertical do painel Properties (`data_panel_vertical_menu.svg`) na Golden Reference (`Blender.svg`).

## Conteúdo

- `data_tab_01.png` a `data_tab_15.png`: Imagens RGBA 22×22 com transparência para a barra vertical de categorias do painel de propriedades (`Tool`, `Render`, `Output`, `Scene`, `World`, `Object`, `Modifiers`, `Data`, `Material`, etc.).

## Uso

Os ícones são carregados pelo `IconRegistry` do Petunia3D e exibidos nos botões de navegação por abas com tingimento dinâmico e feedback de seleção.
