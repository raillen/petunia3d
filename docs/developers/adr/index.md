# Registros de Decisões (ADRs)

Decisões arquiteturais registradas em `docs/architecture/adr/`:

- **001 — Architecture Baseline**: linha de base da arquitetura modular.
- **002 — Rust + OpenGL Stack**: pilha nativa Rust com OpenGL-first e wgpu
  como caminho moderno com fallback automático.

Novas decisões estruturais (fronteiras de crates, persistência, FFI, threading)
devem registrar um ADR numerado sequencial antes ou junto da implementação.
