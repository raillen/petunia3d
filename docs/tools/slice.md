# Ferramenta: Fatiamento (Slice)

A ferramenta **Fatiamento** corta o modelo através de um plano linear contínuo definido pelo usuário na tela.

- **Atalho de Ativação**: `Shift+K`
- **Modos Suportados**: Modo de Edição (`EditMode::Edit`).

## Como Usar
1. Pressione `Shift+K`;
2. Clique e arraste na tela do viewport para traçar a linha do plano de corte;
3. Ao soltar o botão do mouse, todas as arestas e faces que interceptam o plano são cortadas e novos vértices são criados na interseção;
4. Pressione `Escape` para cancelar o corte antes de soltar o mouse.
