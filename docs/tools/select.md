# Ferramenta: Seleção (Select)

A ferramenta **Seleção** é a base de todas as interações no Petunia3D.

- **Atalho de Ativação**: `W` (alterna modos) ou `B` para seleção por caixa.
- **Modos Suportados**: Modo Objeto e Modo de Edição.

## Métodos de Seleção
1. **Clique Simples (`LMB`)**: Seleciona o elemento mais próximo sob o cursor do mouse.
2. **Seleção Aditiva (`Shift + LMB`)**: Adiciona ou remove itens da seleção atual sem perder a seleção prévia.
3. **Seleção por Caixa (`Box Select / B`)**: Clique e arraste um retângulo sobre a área da tela para selecionar todos os elementos contidos.
4. **Selecionar Tudo (`A`) / Desmarcar Tudo (`Alt+A`)**: Alterna rapidamente a seleção em massa de todos os componentes visíveis.
