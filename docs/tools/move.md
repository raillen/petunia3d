# Ferramenta: Mover / Translação (Move)

A ferramenta **Mover** permite transladar objetos ou subcomponentes geométricos (vértices, arestas, faces) no espaço 3D.

- **Atalho de Ativação**: `G` (Grab)
- **Disponível em**: seleção de `Object` e de componentes da malha.

## Como Usar
1. Selecione os elementos que deseja transladar;
2. Pressione `G`;
3. Mova o mouse para posicionar os elementos na nova coordenada;
4. **Travar Eixos**:
   - Pressione `X`, `Y` ou `Z` para travar o movimento no respectivo eixo cartesiano (a linha-guia colorida infinita atravessará o viewport);
   - Pressione `Shift+X`, `Shift+Y` ou `Shift+Z` para travar no plano perpendicular;
5. **Entrada Numérica Direta**: Digite uma distância no teclado (ex: `1.5` ou `-0.2`) e os elementos se moverão com exatidão;
6. **Snap Magnético**: Segure `Ctrl` para ativar o snapping a incrementos de 0.1m;
7. Clique com `LMB` ou pressione `Enter` para confirmar, ou pressione `Escape` / `RMB` para cancelar sem alterações.
