# Ferramenta: Imagem de Referência (Reference Image)

A funcionalidade de **Imagens de Referência** permite importar ilustrações, concept arts ou blueprints técnicos diretamente para o viewport tridimensional.

- **Atalho de Ativação**: `Shift+I` (ou via menu contextual **Add** do viewport ▸ Imagem de Referência).
- **Formatos de Imagem Suportados**: PNG, JPEG e WebP.

## Como Usar
1. Posicione a câmera na vista ortográfica correspondente (`Numpad 1` para vista frontal, `Numpad 3` para lateral);
2. Pressione `Shift+I` ou clique no menu contextual **Add** do viewport;
3. Selecione o arquivo de imagem no diálogo nativo do sistema;
4. O plano de referência é adicionado à cena e listado na seção dedicada `🖼 Imagens de Referência` do Outliner;
5. Você pode alternar a visibilidade pela lista da imagem no painel Parts, ajustar a opacidade no painel Context ou ativar X-Ray para que ela fique visível através dos modelos.
