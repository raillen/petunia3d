# Ferramenta: Corte em Anel (Loop Cut)

O **Loop Cut** analisa as conexões de quadriláteros na malha e insere uma linha contínua de arestas transversais.

- **Atalho de Ativação**: `Ctrl+R`
- **Modos Suportados**: Modo de Edição (`EditMode::Edit`).

## Como Usar
1. Pressione `Ctrl+R`;
2. Aproxime o cursor de uma aresta: uma linha-guia amarela indicará a prévia do corte perpendicular;
3. Clique com o botão esquerdo (`LMB`): o corte é gerado e entra no modo de deslizamento (*slide*);
4. Deslize o mouse para posicionar o anel exatamente onde deseja;
5. Clique novamente com `LMB` para fixar, ou pressione `Escape` para centralizar perfeitamente no meio da face.
