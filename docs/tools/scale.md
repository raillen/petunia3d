# Ferramenta: Escalar (Scale)

A ferramenta **Escalar** redimensiona os elementos selecionados a partir do ponto de pivô.

- **Atalho de Ativação**: `S`
- **Disponível em**: seleção de `Object` e de componentes da malha.

## Como Usar
1. Selecione os elementos;
2. Pressione `S`;
3. Afaste o mouse do pivô para aumentar a escala, ou aproxime-o para diminuir;
4. **Travar Eixos de Escala**:
   - Pressione `X`, `Y` ou `Z` para escalar apenas naquela dimensão;
   - Pressione `Shift+Z` para escalar uniformemente na largura e profundidade (X e Y), mantendo a altura (Z) inalterada;
5. **Fator Numérico**: Digite o fator de escala (ex: `2` para dobrar o tamanho, ou `0.5` para reduzir pela metade);
6. Clique com `LMB` para confirmar ou `Escape` / `RMB` para cancelar.
