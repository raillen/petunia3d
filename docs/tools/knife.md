# Ferramenta: Faca (Knife)

A ferramenta **Faca** permite realizar cortes topológicos livres desenhando novos vértices e arestas diretamente sobre as faces e arestas existentes.

- **Atalho de Ativação**: `K`
- **Modos Suportados**: Modo de Edição (`EditMode::Edit`).

## Como Usar
1. Pressione `K`;
2. O cursor se transforma em uma mira de bisturi com snapping magnético automático a arestas e vértices vizinhos;
3. Clique com `LMB` nos pontos por onde deseja passar o corte;
4. Pressione `Enter` para confirmar os cortes e reconstruir a topologia da malha;
5. Pressione `Escape` ou clique com `RMB` para cancelar a qualquer momento.
