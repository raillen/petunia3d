# Pacotes de Ícones (Icon Packs)

O Petunia3D desacopla os glifos gráficos dos componentes de interface através de um registro abstrato de ícones (`IconRegistry`).

## Pacotes Suportados

| Pacote | Estilo | Espessura de Traço Padrão |
| :--- | :--- | :--- |
| **Petunia (Nativo)** | Cores semânticas autênticas do Blender com traços reforçados | 2.0px – 2.4px |
| **Phosphor** | Linhas geométricas refinadas e universais | 1.8px |
| **Tabler** | Ícones de tecnologia open-source de alta consistência | 1.8px |
| **Iconoir** | Traço minimalista e contemporâneo | 1.6px |
| **Lucide** | Variação moderna e limpa baseada no Feather Icons | 1.8px |

## Alternando o Pacote de Ícones
Acesse as configurações através de **`Editar > Configurações`** (atalho `Ctrl+,`), navegue até a aba **Ícones** e selecione seu pacote favorito. A interface se adapta instantaneamente mantendo o tingimento reativo às cores do tema ativo.
