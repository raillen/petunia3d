# Personalização (Customization)

O Petunia3D adota a política estrita de **Zero Hardcoded Colors** e alta flexibilidade para que o usuário adapte o software às suas preferências visuais e motoras.

## O Que Você Pode Personalizar

- **[Temas Visuais](./themes)**: Paleta completa de cores de interface definida em arquivos TOML, com 4 temas nativos inclusos.
- **[Pacotes de Ícones](./icon-packs)**: 5 icon packs de alta legibilidade (Petunia, Phosphor, Tabler, Iconoir, Lucide) com renderização vetorial sob demanda.
- **[Tradução & Idiomas (i18n)](./translations)**: Arquivos de tradução em formato TOML para traduzir facilmente menus, botões e mensagens.
- **[Perfis de Atalhos (Keymaps)](./keymaps)**: 8 perfis canônicos para usuários vindos do Blender, Maya, 3ds Max, Cinema 4D e teclados sem numpad (Notebooks).
