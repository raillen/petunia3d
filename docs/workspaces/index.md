# Espaços de Trabalho (Workspaces)

Os **Workspaces** do Petunia3D são layouts de interface pré-configurados para tarefas específicas do pipeline de produção 3D. Eles podem ser alternados a qualquer momento através das pílulas no cabeçalho superior (`Top Header`).

## Workspaces Disponíveis

| Workspace | Atalho | Propósito Principal |
| :--- | :--- | :--- |
| **[Modeling](./modeling)** | `F1` | Modelagem geométrica, cortes topológicos, extrusão e transformações por gizmos. |
| **[Paint](./paint)** | `F2` | Pintura de cores de vértices e texturas estilizadas com paletas e pincéis. |
| **[UV](./uv)** | `F3` | Desembrulhamento e organização de ilhas UV no espaço 2D. |
| **[Animation](./animation)** | `F4` | Inserção de keyframes na linha do tempo e inspeção de poses de objetos. |
