# Workspace: UV

O espaço de trabalho **UV** divide a tela entre o Viewport 3D da malha e o Editor 2D de Coordenadas de Textura.

---

## Painéis Ativos no Workspace
- **Editor UV 2D (Esquerda)**: Exibe a malha desembrulhada no espaço quadrado `0.0..=1.0` da textura, com ferramentas para transladar, rotacionar, escalar e empacotar ilhas de coordenadas.
- **Viewport 3D (Direita)**: Permite selecionar faces na malha tridimensional e ver imediatamente quais polígonos correspondem às ilhas no editor 2D.
- **Menu de Unwrapping**: Acesso a projeções ortográficas rápidas (`Project from View`), desembrulhamento inteligente (`Smart UV Project`) e projeção em cubo.
