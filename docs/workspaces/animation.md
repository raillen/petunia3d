# Workspace: Animation

O espaço de trabalho **Animation** configura a interface para o controle de poses e reprodução de movimentos na cena.

---

## Painéis Ativos no Workspace
- **Viewport 3D Superior**: Área de visualização em tempo real das poses e transformações de objetos no espaço.
- **Linha do Tempo Inferior (Timeline)**: Faixa horizontal com numeração de quadros, marcador do cursor temporal atual, botões de transporte (Play/Pause, Primeiro Quadro, Último Quadro) e gravação de quadros-chave (`I`).
- **Painel de Propriedades de Objeto**: Exibe as coordenadas de interpolação de posição, rotação e escala associadas a cada keyframe.
