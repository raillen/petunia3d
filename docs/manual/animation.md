# Linha do Tempo & Animação

O workspace **ANIMATE** oferece uma linha do tempo enxuta e controles de transporte para inspecionar poses e animações básicas de transformação de objetos.

---

## 1. Controles de Transporte

- **Reproduzir / Pausar**: Barra de Espaço (`Space`).
- **Avançar / Retroceder Quadro**: Teclas de seta direita/esquerda (`→` / `←`).
- **Ir para o Início / Fim**: `Shift + ←` / `Shift + →`.

---

## 2. Inserção de Quadros-Chave (Keyframes)

Com um objeto selecionado no Modo Objeto:
- Pressione `I` na linha do tempo para abrir o menu de inserção de Keyframe;
- Escolha entre gravar `Posição (Location)`, `Rotação (Rotation)` ou `Escala (Scale)`.
