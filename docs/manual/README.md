# Manuais de Usuário (`docs/manual/`)

## O que é este diretório?
Contém guias de operação, manuais de instalação, fluxos de modelagem e tutoriais passo a passo para usuários e contribuidores do Petunia3D.

## Inventário
- `installation.md`: Guia de instalação, compilação de binários e requisitos de sistema.
- `usage.md`: Manual prático de operação, navegação de viewport e atalhos de modelagem.
