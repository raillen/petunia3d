# Biblioteca de Assets

A **Biblioteca de Assets** do Petunia3D funciona como uma gaveta retrátil dedicada ao gerenciamento de modelos modulares pré-fabricados dentro do seu projeto.

---

## 1. Salvar Modelo como Asset

Quando você termina de modelar uma peça reutilizável (por exemplo, uma árvore, uma janela ou uma cerca):
1. Selecione o objeto no Modo Objeto;
2. Abra a Gaveta de Assets clicando no botão `📦 Biblioteca de Assets` na barra inferior ou no menu superior;
3. Clique em `💾 Salvar Seleção como Asset`;
4. Defina um nome descritivo e uma categoria (ex: `Cenário / Props`);
5. O modelo agora é parte do catálogo interno do projeto.

---

## 2. Instanciando Assets no Viewport

Para reutilizar um asset gravado:
1. Posicione o 3D Cursor no local desejado da cena usando `Shift + RMB`;
2. Clique sobre o cartão do asset na gaveta;
3. O modelo é instanciado instantaneamente na coordenada exata do 3D Cursor, com sua geometria preservada.
