# Glossário Técnico

- **Ativo (Asset)**: modelo na cena, com UUID persistente e nome.
- **Checkpoint**: snapshot do projeto antes de mutação (base do undo).
- **Coleção**: agrupamento nomeado de ativos no Outliner.
- **Domínio de seleção**: Object, Vertex, Edge ou Face (`0/1/2/3`, `Tab` alterna).
- **Gizmo**: manipulador 3D de Move/Rotate/Scale (`G/R/S`).
- **Modal**: operação interativa (ex. extrusão por arrasto); `Enter` aplica, `Esc` cancela.
- **Perfil (Draw Profile)**: contorno 2D desenhado que vira malha por extrusão ou revolução.
- **Sessão de criação**: transação única de undo ao adicionar primitiva (`Esc` remove).
- **Shelf**: barra contextual sobre a viewport, por workspace/modo.
- **Shape-first**: modelar pela silhueta primeiro, detalhar depois.
- **Slots de região (`UiRegions`)**: retângulos canônicos do shell (header, docks, viewport...).
- **Weld**: fusão de vértices duplicados dentro de uma tolerância.
