# Construindo um Caixote (10 minutos)

O "olá mundo" do Petunia3D: um caixote low-poly com tampa, pronto para exportar.

1. Pressione `A` → **Cube**. Um cubo nasce no 3D Cursor, já selecionado.
2. Pressione `Tab` (modo Face) e clique na face de cima.
3. Pressione `E`, arraste para cima e clique para confirmar: a tampa.
4. Selecione as 4 faces laterais e pressione `I` (Inset) para o friso.
5. `Ctrl+S` para salvar (`caixote.petunia`).
6. Exporte: menu de exportação → OBJ (ou `petunia-cli convert caixote.petunia caixote.obj`).

Desfez algo sem querer? `Ctrl+Z`. Tudo aqui é uma transação de undo.
