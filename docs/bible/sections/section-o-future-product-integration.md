# O — Future Product Integration

Agrupa integração futura por bridge com uma game engine retro/low-poly sem fundir produtos. Feature: P3D-143. O Petunia permanece independente e exportável para outras engines.

[P3D-143 — Game Engine Integration / Bridge](../specs/p3d-143-game-engine-integration-bridge.md)

# Shared 3D Foundation

A estratégia aprovada de reaproveitamento está documentada em [09 — Shared 3D Foundation, Map Editor e Game Engine](../constitution/09-shared-3d-foundation-map-editor-e-game-engin.md).

O objetivo não é fazer a futura engine depender do Petunia3D como aplicação, mas extrair e versionar bibliotecas neutras depois que houver pelo menos dois consumidores reais.
