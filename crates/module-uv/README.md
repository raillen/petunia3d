# Crate `petunia_module_uv` (`crates/module-uv/`)

Implementa as capacidades do workspace **UV**:
- Visualizador e editor bidirecional de coordenadas de textura no espaço UV [0, 1].
- Projeção planar automática baseada no ângulo de visualização da câmera ativa.
- Ferramentas de translação, escala e rotação de ilhas UV com sincronização visual imediata em relação à seleção 3D da malha.
