# Crate `petunia_module_assets` (`crates/module-assets/`)

Implementa a biblioteca de gerenciamento de assets do Petunia3D:
- Lista e navegação entre os múltiplos modelos 3D que compõem a cena do projeto.
- Criação, duplicação, renomeação e exclusão de assets com UUIDs persistentes.
- Pruning automático de recursos e texturas de GPU vinculados a assets removidos.
