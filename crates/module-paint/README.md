# Crate `petunia_module_paint` (`crates/module-paint/`)

Implementa as ferramentas de pintura do workspace **PAINT**:
- Pintura direta de cores em vértices da malha 3D (Vertex Color Painting).
- Edição de canvas albedo 2D sobreposto à malha com preview texturizado em tempo real.
- Pincel livre (Brush), balde de preenchimento (Fill), conta-gotas (Eyedropper com atalho Alt) e gerenciador de paletas retrô.
