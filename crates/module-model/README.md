# Crate `petunia_module_model` (`crates/module-model/`)

Implementa as 12 ferramentas de modelagem poligonal interativa do workspace **MODEL**:
- Inserção de primitivas e guias de referências ortográficas.
- Desenho de perfil sobre imagem de referência (Draw Profile) com extrusão ortogonal ou revolução radial polar.
- Operações de edição topológica: Extrude, Push/Pull, Inset, Bevel, Subdivide, Mirror simétrico e Merge de proximidade.
- Manipuladores gizmo e transformações no espaço tridimensional.
